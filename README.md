# ptool_mini

Минимальная консольная утилита для прошивки устройств с SoC `atmel` и `allwinner`.

Цель утилиты:
- ждать подключение устройства;
- прошить устройство;
- завершиться после результата (успех/ошибка);
- работать в headless-режиме (Ubuntu Server).

## Требования

- Linux (проверено на Ubuntu).
- `cmake` >= 3.18.
- C++ toolchain (`g++`, `make`/`ninja`).
- Доступ в сеть к внутренним git-репозиториям (для `FetchContent`).
- Права на доступ к USB/serial устройствам (обычно запуск через `sudo`).

## Сборка

Из каталога `ptool_mini`:

```bash
cmake -S . -B build
cmake --build build -j4
```

После сборки бинарник:
- `build/ptool_mini`

## Запуск

### Atmel

`--image-path` должен указывать на директорию с образами, например:
- `at91bootstrap.bin`
- `u-boot.bin`
- `*.ubi`

Пример:

```bash
sudo ./build/ptool_mini --cpu atmel --image-path /path/to/images-dir
```

### Allwinner

`--image-path` должен указывать на файл образа.

Пример:

```bash
sudo ./build/ptool_mini --cpu allwinner --image-path /path/to/image-file
```

## Параметры командной строки

- `--cpu <atmel|allwinner>` — целевая платформа.
- `--image-path <path>` — путь к директории (atmel) или файлу (allwinner).
- `--help` — справка по аргументам.
- `--version` — версия приложения.

Внутренний служебный режим:
- `--sam-ba ...` — используется самой утилитой для выполнения команд `sam-ba` в процессе прошивки Atmel.  
  Вручную нужен только для диагностики.

## Типовой сценарий работы

1. Запускаете утилиту с `--cpu` и `--image-path`.
2. Утилита пишет, что ожидает подключение устройства.
3. При подключении начинается прошивка.
4. После результата:
   - успех: утилита завершится с кодом `0`;
   - ошибка: утилита завершится с кодом `1`.

## Логи и сообщения

В консольном режиме для `atmel` оставлены только важные сообщения:
- запуск прошивки;
- стирание данных;
- запись прошивки;
- сообщения категории `DIALOG` (ошибки/подсказки);
- завершение прошивки.

Технический шум (`read32`, дампы адресов памяти и т.п.) скрыт.

## Частые ошибки и что делать

- `Both --cpu and --image-path are required`
  - не переданы обязательные параметры.

- `Unsupported --cpu value. Use: atmel or allwinner`
  - неверное значение `--cpu`.

- `Error: Unknown port 'serial'`
  - не найдены runtime-артефакты `sam-ba` (плагины/metadata).
  - пересоберите проект: post-build шаг должен разложить `lib/qml` и `lib/metadata` в `build`.

- `Permission denied` при открытии `/dev/ttyACM*`
  - недостаточно прав на serial-устройство.
  - используйте `sudo` или настройте udev-группы/права.

- `Hardware revision is 'Unknown'`
  - не удалось корректно прочитать ревизию.
  - проверьте кабель/режим загрузки/доступ к устройству.

- Устройство отключилось во время прошивки
  - утилита завершится с ошибкой.
  - проверьте питание/кабель/контакт перемычки.

## Поведение по ревизии устройства (Atmel)

В текущей версии блокировка прошивки по несовместимой ревизии отключена:
- при mismatch ревизии выводится предупреждение;
- прошивка продолжается принудительно.

## Коды выхода

- `0` — прошивка завершена успешно.
- `1` — ошибка в процессе прошивки.
- `2` — ошибка аргументов командной строки.
